# คำสั่งสำหรับเริ่มตัดคลิป

ช่วยตัดต่อคลิปใน `input/` ตามโจทย์นี้:

ประเภทคลิป: [เช่น รีวิว / vlog / สอน]
แพลตฟอร์ม: [TikTok / Reels / YouTube]
ความยาวเป้าหมาย: [เช่น 45-60 วินาที]
อัตราส่วน: [9:16 / 16:9]
สไตล์: [เช่น กระชับ ดูเป็นธรรมชาติ]
ซับ: [ภาษาไทย / ไม่มี]
เพลง: [ชื่อไฟล์เพลงที่ฉันมีสิทธิ์ใช้ / ไม่ใช้เพลง]

ก่อนแก้ไขไฟล์:
1. ตรวจว่ามีไฟล์ใดบ้างและอ่าน metadata ได้หรือไม่
2. สรุปเนื้อหาที่สามารถยืนยันได้จากสื่อ
3. เสนอ EDL พร้อม timecode และร่างซับ
4. ระบุเครื่องมือที่ต้องใช้และข้อจำกัด
5. รอฉันอนุมัติแผนก่อนเรนเดอร์

ห้ามลบหรือเขียนทับต้นฉบับ และบันทึกผลไว้ใน `output/`
