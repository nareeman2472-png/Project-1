# Mobile Video Editor Starter for Claude Code

ชุดเริ่มต้นสำหรับใช้ **Claude Code ในแอป Claude บน iPhone ผ่าน Cloud Sessions** เพื่อช่วยวางแผนและสร้างเวิร์กโฟลว์ตัดต่อวิดีโอ

> ข้อจำกัดสำคัญ: แอป Claude บน iPhone เป็นหน้าควบคุม ไม่ได้ประมวลผลไฟล์วิดีโอบน iPhone โดยตรง ชุดนี้เป็นแม่แบบโปรเจกต์ ไม่ใช่แอปตัดต่อสำเร็จรูป และไม่ได้รับประกันว่าไฟล์วิดีโอใน Photos จะถูกส่งเข้า Cloud Session ได้โดยตรง

## เริ่มต้นแบบย่อ
1. สร้าง repository ส่วนตัว (Private) บน GitHub
2. อัปโหลดไฟล์จาก ZIP นี้เข้า repository
3. เปิดแอป Claude บน iPhone > แท็บ **Code** > เริ่ม Cloud Session แล้วเชื่อม repository
4. ส่งคำสั่งจาก `prompts/START_HERE_TH.md`
5. ให้ Claude ตรวจสอบไฟล์/เครื่องมือใน environment ก่อนเริ่มงาน
6. นำไฟล์วิดีโอต้นฉบับเข้าพื้นที่ทำงานด้วยวิธีที่ environment รองรับ แล้วให้ Claude สร้างแผนตัดต่อก่อน
7. ตรวจสอบตัวอย่างและอนุมัติก่อน export

## โครงสร้าง
- `CLAUDE.md` — กติกาประจำโปรเจกต์
- `.claude/skills/video-editor/SKILL.md` — ทักษะผู้ช่วยตัดต่อ
- `SETUP_TH.md` — คู่มือติดตั้งบน iPhone
- `WORKFLOW_TH.md` — ขั้นตอนทำงาน
- `prompts/` — คำสั่งพร้อมคัดลอก
- `examples/` — ตัวอย่างไฟล์คำบรรยาย SRT

## ความปลอดภัยและความเป็นส่วนตัว
- อย่าใส่รหัสผ่าน, API key, token หรือข้อมูลส่วนตัวลงใน prompt หรือไฟล์ที่ commit
- ใช้ repository แบบ Private หากมีคลิปส่วนตัว
- อย่าอัปโหลดคลิปของบุคคลอื่นโดยไม่มีสิทธิ์/ความยินยอม
- ให้ Claude แสดงรายการไฟล์ที่จะเปลี่ยนและขออนุมัติก่อนลบหรือเขียนทับ
- เก็บต้นฉบับไว้เสมอ และตรวจสอบลิขสิทธิ์เพลง/ภาพก่อนเผยแพร่

## สิ่งที่ชุดนี้ทำได้ / ไม่ได้
ทำได้: วิเคราะห์โจทย์, วางโครงเรื่อง, ทำ shot list, ร่างคำบรรยาย, สร้างสคริปต์/คำสั่ง FFmpeg เมื่อมีเครื่องมือรองรับ, ตรวจสอบผลลัพธ์เชิงเทคนิค

ไม่ได้รับประกัน: อัปโหลดคลิปจาก Photos โดยตรง, ตัดต่อวิดีโอในตัวแอป Claude, เรนเดอร์ไฟล์ขนาดใหญ่ในทุก Cloud Environment, หรือส่งไฟล์กลับเข้า Photos โดยอัตโนมัติ
