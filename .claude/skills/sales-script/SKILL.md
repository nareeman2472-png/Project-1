# Sales Script Skill — บทขายของ 4 ส่วน

ทุกครั้งที่เขียนบทขายสินค้า ให้เรียงตามลำดับนี้เสมอ ห้ามสลับลำดับ

## โครงสร้างบังคับ
| ส่วน | หน้าที่ | สัดส่วนเวลา (คลิป 30–40 วิ) |
|---|---|---|
| 1. ปัญหาลูกค้า | เปิดด้วยปัญหา/ความกังวลที่กลุ่มเป้าหมายเจอจริง เป็นคำถามหรือประโยคที่คนดูรู้สึก "ใช่ เป็นแบบนี้เลย" | ~10% (3–4 วิ) |
| 2. แบรนด์/สินค้าแก้ปัญหา | โน้มน้าวว่าแบรนด์และสินค้านี้เข้ามาแก้ปัญหาข้อ 1 ได้อย่างไร — บอกชื่อแบรนด์ + ชื่อสินค้า + เชื่อมกลับไปที่ปัญหาโดยตรง | ~20% (6–8 วิ) |
| 3. สรรพคุณ | ส่วนผสมเด่น / คุณสมบัติ / วิธีใช้ (เช้า-กลางคืน, ปริมาณ, ขั้นตอน) — แต่ละข้อผูกกับประโยชน์ที่ลูกค้าได้ | ~45% (14–18 วิ) |
| 4. ปิดการขาย + ตะกร้า | จุดขาย/โปรโมชั่น แล้วชวนกดตะกร้าอย่างชัดเจน | ~20–25% (6–8 วิ) |

## ขั้นตอนการทำงาน
1. ถามเฉพาะที่ยังไม่รู้: สินค้า, กลุ่มเป้าหมาย, ความยาวคลิป, โปรโมชั่น/โค้ดส่วนลด
2. หาข้อมูลสินค้าจริง (ฉลาก, เว็บแบรนด์, ร้านค้าทางการ) ก่อนเขียนส่วนที่ 3 — ห้ามแต่งส่วนผสม/สรรพคุณ/วิธีใช้เอง และแนบแหล่งที่มา
3. เขียนบทตามโครงสร้าง 4 ส่วน
4. ส่งผลลัพธ์ตามรูปแบบด้านล่าง

## รูปแบบผลลัพธ์
1. **บทพากย์** ในโค้ดบล็อก (พร้อมคัดลอกไปทำเสียง) — หนึ่งประโยคต่อบรรทัด
2. **ตารางฉาก**: เวลา | ส่วน (1–4) | บทพากย์ย่อ | ภาพ/วิดีโอที่ต้องถ่าย | ข้อความบนจอ
3. **รายการไฟล์ที่ต้องถ่าย** เรียงตามความสำคัญ
4. **ฟอนต์และสี** (ฟอนต์ฟรีใช้เชิงพาณิชย์ได้ เช่น Kanit, Prompt, Anuphan; อังกฤษหรู: Cinzel, Playfair Display)
5. **ข้อควรระวัง** และแหล่งข้อมูล
6. บันทึกไฟล์ไว้ที่ `scripts/<product>_<version>.md`

## ภาษาและน้ำเสียง
- ภาษาไทยพูดง่าย เป็นกันเอง ประโยคสั้น อ่านออกเสียงได้ลื่น (ประมาณ 4–5 พยางค์/วินาที)
- เขียนชื่อแบรนด์/ส่วนผสมภาษาอังกฤษเป็นคำอ่านไทยในบทพากย์ (เช่น "บาคูชิออล") และใช้ตัวสะกดอังกฤษบนจอ

## กติกาความถูกต้อง
- ใช้คำว่า "ช่วยให้ผิวดู..." แทน "รักษา", "หายขาด", "ลดริ้วรอย 100%" หรือตัวเลขผลลัพธ์ที่แบรนด์ไม่ได้ระบุ
- ห้ามสร้างความเร่งด่วนปลอม (เช่น "เหลือชิ้นสุดท้าย") ถ้าไม่จริง
- โปรโมชั่น/โค้ดส่วนลด: ถ้าผู้ใช้ไม่ให้ตัวเลข ใช้ข้อความกว้าง ๆ ("รับโค้ดส่วนลด") และเตือนให้ตรวจว่ามีจริง
- ห้ามพาดพิงหรือโจมตีแบรนด์คู่แข่ง
