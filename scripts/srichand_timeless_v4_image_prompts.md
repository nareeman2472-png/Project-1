# Srichand Timeless v4 — คำสั่งสร้างรูป (Gemini) ตรงตามเสียงพากย์

## วิธีใช้
1. สร้าง **รูป 00 (นางแบบ)** ก่อน แล้วใช้เป็นรูปอ้างอิงในทุกรูปที่มีคน ใบหน้าจะได้เป็นคนเดียวกันทั้งคลิป
2. รูปที่มีขวด ให้แนบรูปขวดต้นฉบับไปด้วยทุกครั้ง
3. ทุกรูปเป็นแนวตั้ง 9:16 และไม่มีตัวหนังสือ (ผมใส่ข้อความเอง)
4. ตรวจฉลากขวดทุกรูป ถ้าสะกดเพี้ยนให้สร้างใหม่
5. ใช้คนที่ AI สร้างเท่านั้น ห้ามสั่งให้หน้าเหมือนดาราหรือคนจริง และเปิดป้าย AI-generated ตอนโพสต์ TikTok

ต่อท้ายทุกคำสั่ง:
- มีคน: `Use the same woman as the reference portrait.`
- มีขวด: `Keep the serum bottle and label exactly the same as the reference product image.`
- ทุกรูป: `Vertical 9:16, photorealistic, no text, no logos other than the product label.`
